# Apricots Web Port (Non-Official)
## Introduction
A web based port of the GPL licensed game **Apricots**. Apricots was originally published by Mark Snellgrove in 1991. moogers87 became the maintainer of Apricots in 2019.
### Credit
See original README [OriginalREADME.md](OriginalREADME.md)

Official repo for the game itself: [https://codeberg.org/moggers87/apricots/src/branch/runway](https://codeberg.org/moggers87/apricots/src/branch/runway)

### LLM Warning
Given this is a clientside only webpage for a classic game that will not require active maintenance. I have not thoroughly reviewed the code here. The web port was done using Deepseek v4 Flash 0731 Free via OpenCode.

This is not a typical reflection of the quality of my work, I just wanted to make this game accessible to anyone who may not wish to compile it from source.

This is also why I did not publish the project on Codeberg to accompany or be a part of moggers87's repository, as they have a policy against LLM generated content.
